# Compatibility builds

The `compat` branch of this fork builds an unofficial EAS-4-TbSync for
Thunderbird releases upstream has not shipped an update for yet. It is always
released together with the matching TbSync build.

Everything about it - what goes into a build, versions, updates, the release
procedure and how to verify a download - is described in one place:
[COMPAT.md in voigt-it-solutions/TbSync](https://github.com/voigt-it-solutions/TbSync/blob/compat/COMPAT.md).
